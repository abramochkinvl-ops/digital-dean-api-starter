# Вимірювання ПР №2

Цей каталог містить фактичні результати одного базового запуску. Методика, умови й пояснення наведені у [звіті](../../docs/practice-02-report.md).

- `raw.csv` — 180 сирих серій.
- `report.json` — 36 агрегатів, середовище та параметри.
- `encrypt-throughput.png`, `decrypt-throughput.png` — графіки медіани й квартильного діапазону.
- `pytest.txt`, `newman.txt` — фактичні журнали перевірок.
